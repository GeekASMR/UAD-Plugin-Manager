操作法则

第一步：下载部署并运行

在 GitHub Releases 下载压缩包并解压，直接运行 UAD插件管理器.exe，系统将展开赛博控制面板终端。

第二步：生成系统硬件指纹

因为加密规则，请先打开官方的 UAD Control Panel，点击保存 Detailed System Profile 获取官方的详细硬件和授权状态文本文档。

第三步：导入认证并解锁中枢

回到 UAD 插件管理器，在左侧身份层点击「⬇ LOAD UAD PROFILE」，选择上一步生成的文本文件。此时核心数据库将被解密唤醒。

第四步：一键清退冗余计算节点

在解密的列表中手动筛选，或直接点击极客终端的「隐藏未使用/过期插件 (HIDE UNUSED/EXPIRED)」红色按钮，最后重启宿主即可。

💡 注意

我们的操作完全是基于 Windows 文件系统的极速转移与拓展隐藏逻辑，您可以随时通过主界面的「恢复（RESTORE SELECTED）」按钮一键无损找回，非常安全。
